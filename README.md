# 大学日程 · 桌面工作台

一个**免安装绿色版桌面程序**：双击即用，不写注册表、不进开始菜单，整个文件夹可以拷到 U 盘带着走。

界面为**暗色主题**（深灰蓝底 + 高对比文字），长时间盯屏不刺眼。

> 这是一个**空白模板**：首次启动不预置任何课程、事项或记录，所有内容都由你自己录入，
> 或从课表图片一键识别导入。数据 100% 存本机，不联网、不上传。

## 快速开始

1. 双击 `大学日程-桌面工作台-便携版.exe`
2. 首次启动会在 **exe 同级的 `data` 文件夹**里自动建立数据文件，所有记录都存这里
3. 关闭窗口 = 收进右下角托盘继续运行（提醒照常触发）；要完全退出，右键托盘图标选「退出」

> **便携版的数据位置**：electron-builder 的便携 exe 启动时会把程序解压到 `%TEMP%` 的临时目录，
> 所以程序里用的是它注入的 `PORTABLE_EXECUTABLE_DIR`（即便携 exe 真正所在目录），
> 数据不会写进临时目录、不会一退出就丢。
> 如果 exe 放在只读位置（写保护的 U 盘、光盘），会自动退回到用户数据目录，保证仍能保存。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| **总览** | 工作台首页：今日时间轴、四项关键指标、待办速览、作业倒计时、进度概览 |
| **今日** | 按天查看课程，可前后翻日期；课程按时间轴排布，进行中的课会高亮 |
| **待办清单** | 新建待办（优先级 / 截止日 / 标签），按今天、逾期、7 天内筛选，逾期自动标红 |

| **重要事项** | **自己加**：期末考试、竞赛、证书报名……带日期/地点/准备清单，临期倒计时与小红点 |

| **课表识别** | **导入课表图片**，自动读出课程名/星期/节次/教室/周次，逐条确认后写入课表 |
| **运动打卡** | 通用打卡：目标次数、打卡类型、起止日期全部在「设置」里自定义 |
| **饮食记录** | **拍照存档 + 食物库点选 + 文字自动识别营养 + 套餐复用**（详见下节） |
| **智能分析** | 基于你自己课表的空闲时段热力图与时段推荐 |
| **体重作息** | 体重曲线、睡眠、步数记录 |
| **设置** | 数据目录、备份导入导出、提醒、学期起点、蛋白质目标、运动打卡规则、照片管理 |

## 课表识别怎么用

拿到自己的课表后（教务系统截图、拍屏幕、拍纸质版都行）：

1. 打开「课表识别」，点「选择课表图片」或直接把图片拖进去
2. 程序用 Windows 自带的 OCR 引擎**本地识别**（不联网、不上传），先放大再识别，提高小字准确率
3. 识别结果会列成一张表，你逐条核对、改错、取消勾选错的
4. 点「导入课表」，课程就写进「课表」页，周计划、今日、智能分析都会跟着更新

- 截图上最好带「星期一…星期日」的表头和左侧节次，程序靠它们重建表格；没有表头的图会走保守估算，准确率下降
- 周次留空表示「每周都上」；识别漏了可手动填 `1-16` 这类格式
- 识别引擎：Windows.Media.Ocr（中文），照片不出本机

## 重要事项怎么用

「重要事项」是一张**你自己维护的清单** —— 期末考试、竞赛、证书报名、任何要倒计时的事都能加。

- **新建事项**：填名称、日期、时间、地点、分类（考试/竞赛/证书…），可自定义 emoji 图标
- **快捷模板**：期末考试、学科竞赛、证书报名、课程作业 DDL，点一下就把名称和准备清单填好
- **准备清单**：每条事项可以带一串清单项（如「准考证 + 身份证」），考前一天逐条点掉核对
- **提前提醒**：设 `提前 N 天提醒`，进入窗口后顶部出现倒计时、左侧导航出现小红点
- **排序**：未完成在前、按日期升序，没填日期的排最后；可按分类筛选、隐藏已完成
- **复制一份**：适合「每学期都要来一次」的事

数据存在 `data/fitplan-milestones.json`，是可读 JSON，可以直接改或备份。

## 饮食记录怎么用

每天吃饭拍张照，但**照片本身算不出蛋白质** —— 所以设计成「照片留档 + 营养点选」，两步各管一件事：

### 1. 拍照留档
点「📷 选照片 / 拍照」，图片会被拷进 `data/photos/年-月/`，永久保存。
以后能回看「那天到底吃了什么」，不是只留个数字。

### 2. 算蛋白质（三种方式，任选）

**方式 A · 食物库点选（最准，日常推荐）**
内置常见食堂/家常食物，按肉类、蛋奶、水产、豆制品、主食、蔬菜、水果、外卖快餐、零食饮料、补剂分类。
每个都标好份量，比如「鸡腿 1 个（约 100g）= 20g 蛋白 · 180 kcal」。
点一下加入本餐，点两下变两份，自动累加。也可以搜「鸡」「豆腐」快速定位。

**方式 B · 打字识别（最快）**
输入「鸡腿 + 鸡蛋 + 米饭二两」，程序自动分词、匹配食物库、算总数。
支持份数写法，数字在前后都认：`2个鸡蛋`、`3个鸡腿`、`苹果一个`、`鸡蛋两个`、`米饭二两` 都能识别。

**方式 C · 套餐复用（常吃的东西）**
- 内置几套常见组合（标准午餐/晚餐、加餐、早餐组合等），一键套用
- 你也可以把当前清单「存为我的套餐」，下次点 `★ 名字` 直接复用

### 3. 目标怎么定

按通用建议 1.6–2.2 g 蛋白 / kg 体重，程序默认取 1.8：
```
体重 kg × 1.8 = 每日目标（g）
```
- 这个目标会**自动跟着你最近一次体重记录走**（在「体重作息」里记体重即可）
- 系数和手动目标都能在「设置 → 蛋白质目标」里改
- 首页和饮食页都会显示「今天 68g / 目标g，还差 Xg」，达标变绿

> 参考值只是起点。训练量大可以往上调到 2.0–2.2；具体请结合自身情况判断。

### 照片占空间怎么办

`data/photos/` 会随记录增长。设置里可设阈值（默认 500 MB），超了饮食页顶部会提示清理，
也有「打开照片文件夹」按钮直接去删。

## 桌面版专属能力

- **文件持久化**：数据以 JSON 存在 `data/`，不再依赖浏览器缓存，清理浏览器不影响数据
- **系统通知**：课程、作业截止前弹 Windows 通知（在「设置」里开启，可设提前几分钟）
- **托盘常驻**：关窗口不退出，提醒继续生效
- **备份 / 恢复**：一键导出全部数据为 JSON，换电脑导入即可
- **提醒引擎**：每分钟检查一次课程、作业 DDL、待办，同一条只提醒一次

## 数据文件

`data/` 目录下每个模块一个文件，都是可读的 JSON，想手工改也行：

```
data/fitplan-courses.json        课表
data/fitplan-todos.json          待办
data/fitplan-assignments.json    作业
data/fitplan-milestones.json     重要事项（自己加）
data/fitplan-run-logs.json       运动打卡
data/fitplan-health-logs.json    体重/睡眠/步数
data/fitplan-diet-logs.json      饮食记录（含食物明细与照片路径）
data/fitplan-templates.json      自建套餐
data/fitplan-calendars.json      图片识别记录
data/fitplan-settings.json       设置
data/photos/年-月/*.jpg          饮食照片
data/calendars/*.jpg             课表原图
data/profile/                    程序运行缓存（Chromium profile，可随时删）
```

> **备份只需复制上面的 JSON 与 `photos/`、`calendars/`**；`data/profile/` 是可再生的运行缓存，不用备份。
> 程序刻意把 Chromium 的 Cache / Local Storage 等文件隔离进 `profile/` 子目录，
> 免得把要备份的 JSON 淹掉。

> 备份就是把这个 `data` 文件夹整个复制走；或者用「设置 → 导出备份」生成单个 JSON。

## 开发者

```bash
npm install          # 安装依赖
npm run dev          # 浏览器里热更新开发（数据走 localStorage）
npm run electron     # 构建后在 Electron 窗口里跑
npm run smoke        # 冒烟测试（渲染/导航/落盘/饮食计算/重要事项/照片接口）
npm run dark         # 暗色主题校验（底色/对比度，WCAG 标准）
npm run dist         # 打包免安装便携 exe -> release/
npm run dist:dir     # 只打包不压缩，便于调试
npm run icon         # 重新生成图标
```

辅助脚本（都在 `tools/` 下，直接 `node` 跑）：

```bash
node tools/check-timetable.cjs  # 课表 OCR 抽取规则自测（网格重建/连堂/周次/教室解析）
node tools/check-diet.cjs       # 核对饮食记录的营养值与食物库是否一致
node tools/check-parse.cjs      # 验证「苹果一个 / 米饭二两」这类份数写法能否识别
node tools/make-shortcut.cjs --name 工作台   # 在桌面创建「工作台」快捷方式
node electron/measure-startup.cjs            # 测量启动耗时
```

### 启动速度

打开速度上做过这几件事：

- **视图按需加载**：除首屏「总览」外，其余模块都用 `React.lazy` 拆成独立 chunk，冷启动要解析的代码更少。
- **外壳不再每秒重渲染**：顶部时钟拆成独立的 `HeaderClock`，每秒只重渲染那一小块。
- **关掉后台节流**：窗口在 `ready-to-show` 之前是隐藏的，已显式设 `backgroundThrottling: false`。
- **profile 与数据分离**：Chromium 的缓存写进 `data/profile/`，不再和业务 JSON 混在一起。

### 暗色主题说明

组件里用了大量 Tailwind 的 `slate-*` 语义类。整体转暗色时，如果逐个文件改既慢又容易漏，
所以在 `src/index.css` 里加了一层**覆盖映射**：把 `.bg-white`、`.text-slate-700`、`.border-slate-200`
等类统一重定向到暗色值（仅颜色，不动间距和布局）。新写组件只要沿用同样的语义类名，就自动适配暗色。
